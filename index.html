04 / THE PRE-FLIGHT CHECK

Ready, pilot?

Three small steps before you head into orbit.

Review the controls ↗
  1. 01

    Get comfortable.

    Hold the sensor’s mounting board comfortably, in the same orientation throughout play. Leave slack in the wires so they do not pull your hand.

  2. 02

    Find your neutral.

    Hold still during startup calibration and wait for the ready screen. Keep this same neutral position in mind as you play.

  3. 03

    Start small. Have fun.

    When calibration succeeds, gameplay starts automatically. Test small left/right tilts and watch automatic shots on the TFT. Press SW2 only after GAME_OVER to restart.

A BETTER FEEL FOR THE CONTROLS

Something feel off?

The ship moves when I’m holding still.

Return to the position you held during calibration. If it still drifts, restart the device and hold the sensor steady throughout calibration. Keep the mounting orientation consistent.

I do not see a shot yet.

The game fires automatically after its firing interval when no projectile is active. Watch for the current projectile to leave the screen, then look for the next shot.

I see unexpected movement.

Return gently to your calibrated neutral and keep the same grip and orientation. Avoid pulling on the sensor wires while steering.

Do I move the whole controller sideways?

Steer by changing its angle with a gentle tilt. Sliding it left or right across the table is not the intended control. Keep your grip relaxed and use your wrist.

OFFLINE EXPERIMENT / M6

A tiny tilt classifier.

A reproducible software proof of concept, separate from the game running on the LPC1768.

The model takes one number: the current raw MPU6050 X acceleration count minus the neutral X count found at startup. A shallow decision tree assigns LEFT_TILT, NEUTRAL, or RIGHT_TILT. The example values are generated by a written rule, not recorded sensor measurements.

What the generated test shows

1,201 generated values: 1,026 for training and 175 held out. The depth-2 tree has 3 leaves.

≤ -151LEFT_TILT
-150 to 150NEUTRAL
≥ 151RIGHT_TILT

Generated holdout: tree accuracy 1.000 and macro F1 1.000; threshold baseline accuracy 1.000 and macro F1 1.000. Prediction agreement: 1.000. Examples: -151 → LEFT_TILT, -150 → NEUTRAL, 0 → NEUTRAL, 150 → NEUTRAL, 151 → RIGHT_TILT.

The labels come from that threshold rule, so the matching results are expected. These values do not measure real sensor accuracy.

Run python ml/run_all.py to regenerate the labeled CSV, train the tree, compare a threshold baseline, export C, run host tests, and refresh these results. The tree is not running in the firmware; the current game still uses calibrated tilt movement and automatic firing. Next, labeled sensor sessions and an equal-feature comparison on real recordings are needed before considering integration. Read the method, evidence, and limitations ↗
